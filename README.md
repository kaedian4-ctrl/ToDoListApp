# To-Do List App

A simple browser-based task manager built with HTML, CSS, and vanilla JavaScript. Add tasks, track what is complete, and filter the list to focus on all, active, or completed tasks.

## Live Demo

[Try the To-Do List App](https://kaedian4-ctrl.github.io/ToDoListApp/)

## Features

- Add tasks using the input and Add button (or press Enter)
- Mark tasks as complete with a checkbox
- Filter tasks by all, active, or completed
- See how many tasks remain
- Delete individual tasks

## Accessibility

- Interactive controls are native HTML buttons, form inputs, and checkboxes, so they can be reached and used with a keyboard.
- Buttons show a visible focus outline when reached with the keyboard.
- The task input can be submitted by pressing Enter.

## Run locally

Clone or download this repository, then open `index.html` in a web browser. No build tools or dependencies are required.

Tasks are kept in the current page only and are cleared when the page is refreshed or closed.
