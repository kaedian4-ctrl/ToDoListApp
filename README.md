# To-Do List App

A simple browser-based task manager built with HTML, CSS, and vanilla JavaScript.

## Features

- Add tasks
- Mark tasks as complete
- Filter tasks by all, active, or completed
- See how many tasks remain
- Delete tasks

## Run locally

Clone or download this repository, then open `TDLindex.html` in a web browser. No build tools or dependencies are required.

## Technologies

- HTML
- CSS
- JavaScript
